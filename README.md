# Python 기초 퀴즈

터미널에서 객관식 문제를 풀고, 새 문제를 추가할 수 있는 Python 퀴즈 게임입니다. 이번 미션에서 배운 자료형과 반복문 같은 기본 문법을 복습하기 위해 Python 기초를 주제로 골랐습니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python3 main.py
```

## 기능

- **퀴즈 풀기** — 기본 문제 5개와 추가한 문제를 풀고, 정답 여부와 최종 점수를 확인합니다.
- **퀴즈 추가** — 문제, 선택지 4개, 정답 번호를 입력해 저장합니다.
- **퀴즈 목록** — 등록된 문제를 확인합니다.
- **최고 점수** — 지금까지 받은 가장 높은 점수를 확인합니다.
- **종료** — 게임을 종료합니다.

보너스 기능은 아래와 같습니다.

- **랜덤 출제와 문제 수 선택** — 1번에서 풀 문제 수를 고르면 `random.sample()`로 중복 없이 뽑아 섞인 순서로 출제합니다.
- **힌트** — 정답 입력 중 `h`를 누르면 등록된 힌트를 봅니다. 힌트를 본 문제마다 최종 점수에서 10점을 뺍니다. 같은 문제에서 다시 봐도 한 번만 차감하며, 최저 점수는 0점입니다. 새 문제의 힌트는 생략할 수 있습니다.
- **퀴즈 삭제** — 6번에서 삭제할 문제 번호를 고릅니다. `0`은 취소이며 삭제 결과는 파일에 저장됩니다.
- **점수 기록** — 7번에서 완료한 게임의 날짜와 시간, 문제 수, 정답 수, 점수를 최근 순서로 확인합니다.

## 파일 구조

```text
main.py       게임 실행
game.py       메뉴, 퀴즈 풀이, 문제 추가, 목록과 점수 관리
quiz.py       개별 문제를 표현하는 Quiz 클래스
questions.py  기본 문제 5개
storage.py    데이터 저장과 불러오기
state.json    게임이 실행 중에 생성하는 저장 파일
state.json.bak  마지막 정상 저장본의 자동 백업
```

## 코드 설계

- `Quiz`는 문제 하나의 질문·선택지·정답을 보관하고, 문제 출력과 채점을 맡습니다. `QuizGame`은 문제 목록과 최고 점수를 보관하고 메뉴와 게임 진행을 맡습니다.
- 클래스로 관련 데이터와 동작을 묶으면 문제마다 값을 따로 전달할 필요가 줄어듭니다. 상태가 없는 입력 검사에는 `read_number()`와 `read_text()` 같은 함수가 더 간단합니다. 화면에서 받은 입력은 `game.py`에서 검사하고, 파일에서 읽은 값의 구조 검사와 저장은 `storage.py`에서 처리합니다.
- 메뉴를 바꾸려면 `QuizGame.show_menu()`와 `run()`을, 점수 계산을 바꾸려면 `play()`를 수정합니다. 문제 형식을 바꾸면 `Quiz`와 `storage.py`의 읽기·쓰기 형식도 함께 확인해야 합니다.

## 데이터 저장

프로젝트 폴더의 `state.json`에 UTF-8로 저장합니다. `quizzes`에는 문제(`question`), 선택지(`choices`), 정답 번호(`answer`)가 들어갑니다. `best_score`는 최고 점수이며, 아직 기록이 없으면 `null`입니다. 다시 실행할 때는 저장된 문제와 점수를 불러옵니다.

`quizzes`는 문제 순서를 유지하기 위해 목록으로 저장하고, 각 문제의 질문·선택지·정답은 한 객체에 묶었습니다. `answer`는 화면과 같은 1~4번을 사용합니다. 전체 게임의 최고 점수인 `best_score`는 문제 목록과 나란히 둡니다. 각 문제의 `hint`는 생략하면 `null`이고, `history`는 완료한 게임의 날짜·시간(`played_at`), 문제 수(`total`), 정답 수(`correct`), 힌트 사용 수(`hints_used`), 점수(`score`)를 담는 목록입니다. 이전 저장 파일은 기존 문제와 최고 점수를 유지하며, 점수 기록은 새로 완료한 게임부터 쌓입니다.

실행 시 JSON을 읽고 필드와 값의 범위를 검사합니다. `state.json`이 없거나 손상됐으면 `state.json.bak`에서 문제와 최고 점수를 복구합니다. 두 파일 모두 사용할 수 없으면 기본 문제로 시작합니다. 문제 추가·삭제, 게임 완료, 종료 시에는 임시 파일을 완성한 뒤 `state.json`을 교체합니다. 정상 저장 후 같은 내용을 `state.json.bak`에 자동으로 백업합니다.

JSON은 표준 라이브러리로 읽고 쓰기 쉽고 파일을 직접 확인할 수 있어 이 정도 규모에 적합합니다. 이 프로그램은 저장할 때 전체 파일을 다시 쓰고 읽을 때 전체 데이터를 메모리에 올립니다. 문제 수가 많아지거나 여러 사용자가 동시에 쓰는 경우에는 일부 데이터만 조회·수정할 수 있는 SQLite 같은 데이터베이스가 더 적합합니다.

저장에 실패하면 경로와 쓰기 권한을 확인합니다. 프로그램이 열려 있으면 메뉴 5번으로 종료하면서 저장을 다시 시도할 수 있습니다. 백업으로 실행한 뒤 5번으로 종료하면 복구한 내용이 `state.json`에 다시 저장됩니다.

복사본에서 `state.json`을 손상시킨 뒤 다시 실행해 백업 복구를 확인했습니다.

```text
state.json 파일을 읽을 수 없습니다.
백업에서 퀴즈 6개를 복구했습니다.
최고 점수: 100점
```

## 실행 결과

기본 문제 5개에서 한 문제를 추가해 6문제를 풀었습니다. 종료 후 다시 실행해 추가 문제와 최고 점수가 유지되는 것을 확인했습니다. 다음은 실행 화면의 주요 출력입니다.

```text
=== Python 기초 퀴즈 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 최고 점수
5. 종료

[문제 추가] 퀴즈를 추가하고 저장했습니다.
[풀이 결과] 결과: 6문제 중 6문제 정답 (100점)
[재실행] 저장된 퀴즈 6개를 불러왔습니다.
[목록] 6. 파이썬의 확장자명은?
[점수] 최고 점수: 100점
[잘못된 입력] 숫자를 입력해 주세요. / 1~5 사이의 숫자를 입력해 주세요. / 값을 입력해 주세요.
[Ctrl+C] 입력이 중단되어 게임을 종료합니다.
```

## Git 작업 기록

원격 저장소는 [codyssey-mission2](https://github.com/YangGang02/codyssey-mission2)입니다. 메뉴, 문제 클래스, 풀이, 추가, 점수, 저장 기능을 각각 커밋했고, 메시지에는 구현한 내용을 짧게 적었습니다. 퀴즈 풀기는 `git checkout -b feature/quiz-play`로 분리하고 구현 후 `main`에 `git merge --no-ff feature/quiz-play`로 병합했습니다.

별도 폴더에 `git clone`한 뒤 게임 실행을 확인하고 README 변경을 커밋해 푸시했습니다. 원본 폴더에서 `git pull --ff-only`를 실행해 복제본의 커밋 `0aca034`가 반영된 것을 확인했습니다.

```text
$ git rev-list --count main
16

$ git branch --list
  feature/quiz-play
* main

$ git log --oneline --graph --all
...
* 77d836b 퀴즈 추가와 입력 검사 구현
*   7335423 Merge: 퀴즈 풀이 기능 병합
|\
| * 5bad3f9 퀴즈 출제와 정오답 및 결과 표시 구현
|/
* be0c7e5 게임 진행을 QuizGame 클래스로 분리
```

커밋 수는 이 문서를 보완하기 전 기준이며, 그래프는 병합 구간을 발췌했습니다.
